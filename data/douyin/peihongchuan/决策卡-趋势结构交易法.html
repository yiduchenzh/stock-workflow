裴洪川《趋势结构交易法》· 一次交易决策 SOP
七道闸门，全过才动手；任何一道不过 → 回到「等」
① 定级别
周线 / 日线 / 60分钟 三个级别都看清。只看单级别 = 没看清。
↓
② 定趋势 模块1
有明确高低点序列？处在 形成 / 延续 / 结束 哪一期？
大级别下跌 + 小级别上涨 = 只是反弹 → 停。
不过 → 空仓等
↓
③ 验结构 模块2 · 灵魂
高低点像楼梯（HH+HL）？回调破 0.618 / 前低 了吗？
无序 = 震荡 = 坚决不操作。
不过 → 坚决不操作，回①
↓
④ 等位置 模块3
是苹果吗（回调到位，不是半山腰）？还是震荡突破（收盘破前高）？
回调是轻度回调还是上涨到阻力区后的下跌（=反转）？
90% 的时间花在这一步：等。
没到位 / 是反转 → 继续等
↓
⑤ 等信号 模块4
方向：50线上方且破前高 / 60线向上且价在线上 / 年线上方？
节奏：周线MACD 零轴上金叉？关键位出现看涨吞没？
方向错 → 金叉也是假信号。
方向不对 → 不做
↓
⑥ 下单 模块5
在图上标出 C 点（交易失效位） → 止损设在C下方。
盈亏比 ≥ 3:1 ？ 不够 → 不做。画不出止损 → 不做。
仓位：总资金 10–20% 起步。
画不出止损 / 赔率不够 → 不做
↓
⑦ 持仓：只盯两件事
日线失效位破没破？· 60分钟结构低点破没破？
都没破 → 拿着（"上涨趋势还在，你怕啥"）。
破了 → 走：不等反弹，不等回本。

内核一句话

  • 趋势给方向，结构给操作
  • 市场只有 上涨 / 下跌 / 震荡，交易做的是「转化」那一刻
  • 「就算选对品种，找不对时机照样白搭」

他明确说不看的

  • 成交量 · 筹码 · 指标 · 资金
  • 「所有信息都会体现在趋势上」
  • ⚠️ 但均线/MACD 他又拿来当 确认/节奏 工具 —— 只做最后一票否决，不用来找票

按「不该做」记更快

  • 下跌趋势里半空接刀子
  • 回调没到位就冲
  • 均线向下时的 MACD 金叉
  • 见一根阳线就抄底
  • 买低价股

实证提醒（全市场实测）

  • 「年线上方 / MA60多头 / 均线+MACD共振 / 上半月」→ 20日均值收益无 alpha，部分为负
  • 但追高型 5%分位亏损 −20.7%~−21.6%，下跌中买入仅 −16.2%
  • → 风险控制成立，alpha 不成立
拿走这两样就值了：
① 止损 = 交易失效位（不是固定百分比）
② 3:1 固定盈亏比
