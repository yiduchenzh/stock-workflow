## 〇、她的核心视角

**讲的是"主力（操盘手）视角"，不是散户技术分析** —— 通篇在回答一个问题：
**"如果我是操盘手，我现在在干什么？"**

- 核心命题：**算主力的账，而不是算自己的账**（第18期原话）
- 主力只做一件事：**利用散户的恐慌和贪婪** —— 下跌时吓你卖，上涨时诱你买
- 所以所有信号都是**反直觉的**：真拉升"不像要涨"，危险盘"是红的"，抗跌"不是强势"

## 二、买卖规则

### 2.1 总纲（跟庄铁律）
> **买在分歧，卖在一致**

### 2.2 买点
1. **三大低吸位**（第8期）—— 特征是"盘面上看起来都不像机会"
   - 缩量止跌位
   - 试盘砸坑位
   - 突破回踩位
2. **真启动三信号**：量能温和 / 结构突破 / 筹码锁定
3. **洗盘两大买点**（第10期）
   - **上影线成本置换**：第二天**跳空高开 + 成交量温和放大**的上影线 → 可买（前提：前一根上影线的高点被突破）
   - **低开洗盘型**：洗盘往往高开高走，出货才低开闷杀 → **看开盘价，不看收盘价**
4. **执行纪律**：**分三批入场** + 严格止损（第8期）

### 2.3 卖点 / 离场信号
| 信号 | 出处 |
|---|---|
| 跌破 **5 日线或 10 日线** | 第17期 |
| **高位放量破线** | 第17期 |
| 派发三标准：**位置到位 / 换手到位 / 封单变薄** | 第2期 |
| 出货三征兆：**高、放、滞** | 第2期 |
| **退潮信号**：高标见顶 / 天地板 / 按钮信号 | 第9期 |
| 上影线 + **低开且 5 日均线拐头向下** → 需卖 | 第10期 |

### 2.4 情绪周期与仓位（第9期）
| 周期 | 做法 |
|---|---|
| **退潮期** | 核心票见底可继续持有，否则**空仓** |
| **混沌期** | **分仓试错聚焦**，等待方向；**避免追首板** |
| **补涨阶段** | 等**龙头打出高度**，找低位票和经典图形；避免前期暴涨过的票 |
| **老龙头** | 人气散去，难以再创新高 → **避免追高** |

> 结语原话：**建立自己的交易模式，找出赚钱最多的一招，改进并找到极致买点。**

## 三、九条可执行的检查清单

| # | 规则 | 出处 |
|---|---|---|
| 1 | **算主力的账**：主力成本区 = 阳线多阴线少、阳线放量阴线缩量的箱体；30 个点内震荡不破位可持有 | 第18期 |
| 2 | **真假缩量**：超跌反弹后的缩量 = **假**；底部锁仓后的缩量 = **真**。硬标准：换手率萎缩 + 看试盘（不看K线）+ 算主力的账 | 第17期 |
| 3 | **缩量横盘三看**：位（累计换手+筹码分布辨真假低位）/ 单（挂单判主力在否）/ 量（量价对倒，防假缩量假支撑）。低位缩量横盘可留，**高位横盘缩量删自选** | 第15期 |
| 4 | **追涨前过三关三问**：位置（套牢盘消化否）/ 形态（启动还是加速）/ 仓位（主力状态）；量化指标：**90% 成本集中度、累计换手率、股东户数、户均持股** | 第12期 |
| 5 | **炸板分辨**：**被动卖**（老主力清洗新主力 → 后面有拉升机会）vs **主动卖**（有预谋拆单出货、磨档阴跌、专挑情绪好的时段）→ 看量（谁跟谁换手）、看承接（龙虎榜）、看情绪周期、看次日（高开=弱转强 / 低开跳水=出货） | 第11期 |
| 6 | **涨停后阴线**：出货**不砸绿盘**，危险的是**红盘**。判断 = **缩量不破**（量要缩、位要守，位看四道防线）。三步：**量、位、动** | 第5期 |
| 7 | **打板三要素**：**势**（题材的势+反弹势能+主线产业强逻辑）、**对**（龙头辨识度+板块梯队）、**仓**（主力仓位 → 直线拉升/横盘后封板/涨停回封三种形态） | 第14期 |
| 8 | **次新股三看**：天时（全市场无题材可炒、亏钱效应出来时）/ 日子（盯 C 字头**摘C日期**）/ 盘面（机构要主流热点方向+盘子足够大）。散户策略：**不破线、缩量住、放量站**。避坑：不追前 5 天无限制拉升、题材火热时不做次新 | 第4期 |
| 9 | **暴跌日选票**：抗跌 ≠ 强势。暴跌日当天不干活，**收盘后看跌幅榜前 50，找缩量最狠的**；避开**逆势放量大红**的票 | 第16期 |
