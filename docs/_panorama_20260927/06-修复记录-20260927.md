`backend/main.py:117` 的 em_node 补丁劫持 `httpx.Client.get(url, params=...)`，但只把 `url` 交给 `em_node.get_json()`，**丢掉了 `params`** → 请求没有 `secid/fields` → 东财返回 `{"rc":102,"data":null}` 且 HTTP 200 → `f43=None` → `(None or 0)/100 = 0.0`。**静默归零，不抛异常**。

| 探针 | 输入 | 返回 |
|---|---|---|
| ① 复现（补丁走的路径） | `em_node.get_json(PUSH2)` 无 query | `{"rc":102,"data":null}` → price 0.0 |
| ② 带正确 query | `em_node.get_json(PUSH2 + "/api/qt/stock/get?secid=100.DJIA&fields=...")` | `{"rc":0,"data":{"f43":5182862,"f170":93,"f58":"道琼斯"}}` → 51828.62 (+0.93%) |
| ③ 绕开 em_node 直连 | `httpx.get(PUSH2, params=...)` | `RemoteProtocolError: Server disconnected`（这正是当初引入 em_node 的原因） |

**影响面（全仓扫描）**：只有 2 个调用方用 `params=` 调 push2*，**都中招**——
`data_service.py:948` `_poll_global_indices`（全球指数）＋ `data_service.py:973` `_fetch_page`（**东财全市场分页降级路径**，被 `:682/:710` 调用）。其余走"完整 URL 带 query"的调用方不受影响（所以板块/概念页正常，掩盖了这个 bug）。

## 修复
`backend/main.py`：`_em_try(url, params=None)` —— 把 `params` 用 `urlencode(doseq=True)` 合并进 query 再交给 em_node；同步/异步两处调用点传 `kw.get("params")`。**一处修，两条路径受益**。（未跑 py_compile，pyc 守卫安全：273,017 字节）
