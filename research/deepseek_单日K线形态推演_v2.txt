其实这里有两个核心点：

趋势：缠论本身对趋势有明确定义——趋势就是至少两个同向中枢依次抬高或降低。之前我们的代码里，只用MA20做了一个简单的趋势过滤，但这并不符合缠论对趋势的定义。缠论的趋势是结构性的，不是均线性的。

小周期推大周期：这个逻辑是，1分钟走完的走势，会逐步构成5分钟的一笔，5分钟的一笔逐步构成15分钟的一笔，15分钟的一笔逐步构成30分钟的一笔，30分钟的中枢逐步构成日线的中枢。所以从小周期到大周期，是一个递归的过程。

用户希望我把这两点补充进去，做一个更完整的推理。

你说得对，之前融合缠论时，趋势处理得太粗糙——只用 MA20 做了一个简单过滤，这不符合缠论对趋势的定义。而且小周期到大周期的推断，应该是一个结构递归过程，而不是简单的 K 线聚合。下面把这两块补齐。

2. 趋势力度
趋势力度由中枢移动的斜率和背驰决定：

中枢依次抬高，且每段离开中枢的力度递增 → 趋势加速；

中枢依次抬高，但离开力度递减 → 趋势背驰，可能反转；

中枢不再抬高，开始重叠 → 趋势结束，进入盘整。

3. 趋势级别
趋势的级别由中枢级别决定：

1 分钟中枢构成 1 分钟趋势；

5 分钟中枢构成 5 分钟趋势；

30 分钟中枢构成 30 分钟趋势；

依次递归。

二、小周期逐步推断大周期预期
这是缠论最核心的递归逻辑，也是你前面推理的自然延伸。

1. 递归链条
text
1分钟分型 → 1分钟笔 → 1分钟线段 → 1分钟中枢
                                    ↓
                          构成 5分钟的一笔
                                    ↓
5分钟分型 → 5分钟笔 → 5分钟线段 → 5分钟中枢
                                    ↓
                          构成 30分钟的一笔
                                    ↓
30分钟分型 → 30分钟笔 → 30分钟线段 → 30分钟中枢
                                    ↓
                          构成日线的一笔
2. 关键规则
小周期走势类型的完成，构成大周期的一笔。

具体说：

1 分钟的一个完整走势类型（趋势或盘整），构成 5 分钟的一笔；

5 分钟的一个完整走势类型，构成 30 分钟的一笔；

30 分钟的一个完整走势类型，构成日线的一笔。

大周期的中枢，由小周期的走势类型重叠构成。

5 分钟中枢 = 至少三个 1 分钟走势类型的重叠；

30 分钟中枢 = 至少三个 5 分钟走势类型的重叠；

日线中枢 = 至少三个 30 分钟走势类型的重叠。

3. 实时推断逻辑
当 1 分钟还在走时：

1 分钟的当前走势类型未完成 → 5 分钟当前笔未完成；

5 分钟当前笔未完成 → 5 分钟分型未确认；

5 分钟分型未确认 → 5 分钟笔无法构造；

5 分钟笔无法构造 → 5 分钟中枢无法确认；

5 分钟中枢无法确认 → 30 分钟结构无法更新。

当 1 分钟走势类型完成时：

1 分钟走势类型完成 → 5 分钟一笔完成；

5 分钟一笔完成 → 5 分钟分型可能确认；

5 分钟分型确认 → 5 分钟笔更新；

5 分钟笔更新 → 5 分钟中枢可能更新；

5 分钟中枢更新 → 30 分钟结构可能更新。

所以：

小周期每完成一个走势类型，大周期的当前笔就推进一步；大周期笔的完成，又推进更大周期的结构。

4. 大周期预期推断
当小周期走到某个关键位置时，可以推断大周期的预期：

小周期状态	大周期预期
1 分钟趋势向上，且未背驰	5 分钟当前笔继续向上，可能突破前高
1 分钟趋势向上，但出现背驰	5 分钟当前笔可能结束，形成顶分型
1 分钟趋势向下，且未背驰	5 分钟当前笔继续向下，可能跌破前低
1 分钟趋势向下，但出现背驰	5 分钟当前笔可能结束，形成底分型
1 分钟盘整，中枢延伸	5 分钟当前笔继续震荡，方向未定
1 分钟盘整，中枢新生	5 分钟当前笔可能启动新方向

下面把趋势识别、小周期推大周期、多级别联立补进代码。

# -*- coding: utf-8 -*-
"""
补全版：
  1. 缠论趋势识别（中枢依次抬高/降低 + 背驰）
  2. 小周期走势类型完成 → 大周期笔推进
  3. 多级别联立：日线定趋势，30分钟定中枢，5分钟定扳机
"""

import pandas as pd
import numpy as np
from dataclasses import dataclass, field
from typing import List, Optional, Dict, Tuple
from enum import Enum


# =========================================================
# 基础结构
# =========================================================

@dataclass
class Bar:
    dt: str; o: float; h: float; l: float; c: float; v: float = 0.0

    @property
    def body(self): return abs(self.c - self.o)
    @property
    def upper_shadow(self): return self.h - max(self.o, self.c)
    @property
    def lower_shadow(self): return min(self.o, self.c) - self.l
    @property
    def amplitude(self): return self.h - self.l


class FractalType(Enum):
    TOP = "顶"; BOTTOM = "底"

@dataclass
class Fractal:
    type: FractalType; idx: int; h: float; l: float; dt: str

@dataclass
class Stroke:
    start: Fractal; end: Fractal; direction: int

@dataclass
class Center:
    zg: float; zd: float; start_idx: int; end_idx: int
    strokes: List[Stroke] = field(default_factory=list)
    @property
    def height(self): return self.zg - self.zd


class TrendType(Enum):
    UP = "上涨趋势"
    DOWN = "下跌趋势"
    CONSOLIDATION = "盘整"


@dataclass
class Trend:
    type: TrendType
    centers: List[Center]
    strength: float          # 趋势力度：中枢移动斜率
    diverged: bool           # 是否背驰
    level: str               # 级别：1m/5m/30m/1d


# =========================================================
# 缠论基础函数
# =========================================================

@dataclass
class MergedBar:
    dt_start: str; dt_end: str; h: float; l: float; direction: int

def merge_inclusion(bars: List[Bar]) -> List[MergedBar]:
    if not bars: return []
    merged = [MergedBar(bars[0].dt, bars[0].dt, bars[0].h, bars[0].l, 1)]
    direction = 1
    for bar in bars[1:]:
        last = merged[-1]
        contained = (bar.h <= last.h and bar.l >= last.l) or \
                    (bar.h >= last.h and bar.l <= last.l)
        if not contained:
            direction = 1 if (bar.h > last.h and bar.l > last.l) else -1
            merged.append(MergedBar(bar.dt, bar.dt, bar.h, bar.l, direction))
        else:
            if direction == 1:
                nh, nl = max(last.h, bar.h), max(last.l, bar.l)
            else:
                nh, nl = min(last.h, bar.h), min(last.l, bar.l)
            merged[-1] = MergedBar(last.dt_start, bar.dt, nh, nl, direction)
    return merged

def find_fractals(merged: List[MergedBar]) -> List[Fractal]:
    out = []
    for i in range(1, len(merged)-1):
        p, c, n = merged[i-1], merged[i], merged[i+1]
        if c.h > p.h and c.h > n.h and c.l > p.l and c.l > n.l:
            out.append(Fractal(FractalType.TOP, i, c.h, c.l, c.dt_end))
        elif c.l < p.l and c.l < n.l and c.h < p.h and c.h < n.h:
            out.append(Fractal(FractalType.BOTTOM, i, c.h, c.l, c.dt_end))
    return out

def build_strokes(fractals: List[Fractal], min_gap: int = 3) -> List[Stroke]:
    if not fractals: return []
    filt = [fractals[0]]
    for f in fractals[1:]:
        last = filt[-1]
        if f.type == last.type:
            if f.type == FractalType.TOP and f.h > last.h: filt[-1] = f
            elif f.type == FractalType.BOTTOM and f.l < last.l: filt[-1] = f
        else:
            filt.append(f)
    strokes = []
    i = 0
    while i < len(filt)-1:
        a, b = filt[i], filt[i+1]
        if abs(b.idx - a.idx) >= min_gap:
            strokes.append(Stroke(a, b, 1 if b.type == FractalType.TOP else -1))
            i += 1
        else:
            i += 1
    return strokes

def find_centers(strokes: List[Stroke], min_strokes: int = 3) -> List[Center]:
    centers = []
    i = 0
    while i + min_strokes - 1 < len(strokes):
        group = strokes[i:i+min_strokes]
        highs = [max(s.start.h, s.end.h) for s in group]
        lows  = [min(s.start.l, s.end.l) for s in group]
        zg, zd = min(highs), max(lows)
        if zg > zd:
            centers.append(Center(zg, zd, group[0].start.idx,
                                  group[-1].end.idx, group))
        i += 1
    return centers


# =========================================================
# 趋势识别（核心补全）
# =========================================================

def identify_trend(centers: List[Center],
                   strokes: List[Stroke],
                   level: str = "1m") -> Trend:
    """
    缠论趋势识别：
      上涨趋势：至少两个中枢，依次抬高
      下跌趋势：至少两个中枢，依次降低
      盘整：只有一个中枢，或中枢重叠
    趋势力度：中枢移动斜率 + 离开段力度
    背驰：同向走势力度衰竭
    """
    if len(centers) < 2:
        return Trend(TrendType.CONSOLIDATION, centers, 0.0, False, level)

    # 判断中枢是否依次抬高/降低
    ups = 0
    downs = 0
    for i in range(1, len(centers)):
        prev_c, cur_c = centers[i-1], centers[i]
        if cur_c.zd > prev_c.zd and cur_c.zg > prev_c.zg:
            ups += 1
        elif cur_c.zd < prev_c.zd and cur_c.zg < prev_c.zg:
            downs += 1

    if ups >= 1 and ups >= downs:
        trend_type = TrendType.UP
    elif downs >= 1 and downs > ups:
        trend_type = TrendType.DOWN
    else:
        trend_type = TrendType.CONSOLIDATION

    # 趋势力度：最后一个中枢相对第一个中枢的移动幅度
    if len(centers) >= 2:
        move = abs(centers[-1].zg - centers[0].zg)
        n_seg = len(centers) - 1
        strength = move / n_seg if n_seg > 0 else 0.0
    else:
        strength = 0.0

    # 背驰：比较最后两段同向走势的力度
    diverged = False
    if len(strokes) >= 4:
        # 最后两段同向笔
        last = strokes[-1]
        prev_same = None
        for s in reversed(strokes[:-1]):
            if s.direction == last.direction:
                prev_same = s
                break
        if prev_same:
            last_amp = abs(last.end.h - last.start.l) if last.direction == 1 \
                       else abs(last.start.h - last.end.l)
            prev_amp = abs(prev_same.end.h - prev_same.start.l) if prev_same.direction == 1 \
                       else abs(prev_same.start.h - prev_same.end.l)
            if prev_amp > 0 and last_amp < prev_amp * 0.8:
                diverged = True

    return Trend(trend_type, centers, strength, diverged, level)


# =========================================================
# 小周期 → 大周期递归推断
# =========================================================

@dataclass
class LevelState:
    """某一级别的当前状态"""
    level: str
    bars: List[Bar]
    merged: List[MergedBar] = field(default_factory=list)
    fractals: List[Fractal] = field(default_factory=list)
    strokes: List[Stroke] = field(default_factory=list)
    centers: List[Center] = field(default_factory=list)
    trend: Optional[Trend] = None
    current_stroke_done: bool = False   # 当前笔是否完成
    current_trend_done: bool = False    # 当前走势类型是否完成


def update_level_state(level: str, bars: List[Bar],
                       min_gap: int = 3) -> LevelState:
    """更新某一级别的全部结构"""
    merged = merge_inclusion(bars)
    fractals = find_fractals(merged)
    strokes = build_strokes(fractals, min_gap=min_gap)
    centers = find_centers(strokes, min_strokes=3)
    trend = identify_trend(centers, strokes, level)

    state = LevelState(
        level=level, bars=bars, merged=merged,
        fractals=fractals, strokes=strokes,
        centers=centers, trend=trend,
    )

    # 判断当前笔是否完成：最后一个分型与倒数第二个分型间隔足够
    if len(fractals) >= 2:
        state.current_stroke_done = abs(fractals[-1].idx - fractals[-2].idx) >= min_gap

    # 判断当前走势类型是否完成：
    # 如果出现背驰，或中枢方向反转，认为走势可能完成
    if trend.diverged:
        state.current_trend_done = True

    return state


def infer_higher_level_expectation(lower: LevelState) -> Dict:
    """
    根据小周期状态，推断大周期当前笔的预期。
    返回：
      - 大周期当前笔方向预期
      - 是否可能形成分型
      - 是否可能结束当前笔
    """
    result = {
        "lower_level": lower.level,
        "trend": lower.trend.type.value if lower.trend else "未知",
        "diverged": lower.trend.diverged if lower.trend else False,
        "stroke_done": lower.current_stroke_done,
        "expectation": "",
    }

    if lower.trend is None:
        result["expectation"] = "结构不足，无法推断"
        return result

    if lower.trend.type == TrendType.UP:
        if lower.trend.diverged:
            result["expectation"] = "小周期上涨背驰，大周期当前笔可能结束，形成顶分型"
        else:
            result["expectation"] = "小周期上涨未背驰，大周期当前笔继续向上"
    elif lower.trend.type == TrendType.DOWN:
        if lower.trend.diverged:
            result["expectation"] = "小周期下跌背驰，大周期当前笔可能结束，形成底分型"
        else:
            result["expectation"] = "小周期下跌未背驰，大周期当前笔继续向下"
    else:
        if lower.current_stroke_done:
            result["expectation"] = "小周期盘整，大周期当前笔方向待定，可能中枢延伸"
        else:
            result["expectation"] = "小周期盘整中，大周期当前笔未完成"

    return result


# =========================================================
# 多级别联立
# =========================================================

def multi_level_analysis(bars_1m: List[Bar],
                         bars_5m: List[Bar],
                         bars_30m: List[Bar],
                         bars_1d: List[Bar]) -> Dict:
    """
    多级别联立：
      日线定趋势
      30分钟定中枢
      5分钟定笔
      1分钟定扳机
    """
    s1 = update_level_state("1m", bars_1m, min_gap=3)
    s5 = update_level_state("5m", bars_5m, min_gap=3)
    s30 = update_level_state("30m", bars_30m, min_gap=3)
    sd = update_level_state("1d", bars_1d, min_gap=3)

    result = {
        "日线趋势": sd.trend.type.value if sd.trend else "未知",
        "日线背驰": sd.trend.diverged if sd.trend else False,
        "30分钟趋势": s30.trend.type.value if s30.trend else "未知",
        "30分钟中枢数": len(s30.centers),
        "5分钟趋势": s5.trend.type.value if s5.trend else "未知",
        "5分钟当前笔完成": s5.current_stroke_done,
        "1分钟趋势": s1.trend.type.value if s1.trend else "未知",
        "1分钟背驰": s1.trend.diverged if s1.trend else False,
    }

    # 小周期推大周期预期
    result["1m推5m"] = infer_higher_level_expectation(s1)
    result["5m推30m"] = infer_higher_level_expectation(s5)
    result["30m推日线"] = infer_higher_level_expectation(s30)

    # 联立判断
    daily_up = sd.trend and sd.trend.type == TrendType.UP
    m30_up = s30.trend and s30.trend.type == TrendType.UP
    m5_up = s5.trend and s5.trend.type == TrendType.UP

    if daily_up and m30_up and m5_up:
        result["联立结论"] = "三级别共振向上，回调即买点"
    elif daily_up and m30_up and not m5_up:
        result["联立结论"] = "日线与30分钟向上，5分钟回调，等待5分钟底分型"
    elif not daily_up and m30_up:
        result["联立结论"] = "日线未确认，30分钟反弹，谨慎参与"
    else:
        result["联立结论"] = "级别不共振，观望"

    return result


# =========================================================
# 融合趋势后的买卖点
# =========================================================

def generate_signals_v3(df: pd.DataFrame,
                        min_gap: int = 3,
                        vol_confirm: float = 1.2) -> pd.DataFrame:
    """
    融合缠论趋势后的买卖点：
      只在日线趋势向上时做多
      30分钟中枢突破 + 5分钟分型确认 → 三买
      日线趋势向下 + 30分钟背驰 + 5分钟底分型 → 一买
    """
    trades = []
    bars = [Bar(str(r.date.date()), r.open, r.high, r.low, r.close, r.volume)
            for r in df.itertuples()]

    position = 0
    entry_price = 0.0
    entry_date = ""
    stop_loss = 0.0
    take_profit = 0.0
    buy_type = ""
    highest = 0.0

    for i in range(60, len(bars)):
        window = bars[max(0, i-60):i+1]
        state = update_level_state("daily", window, min_gap=min_gap)
        trend = state.trend
        today = bars[i]
        prev = bars[i-1]

        # 量能
        if i >= 5:
            avg_v = sum(b.v for b in bars[i-5:i]) / 5
            vr = today.v / avg_v if avg_v > 0 else 1.0
        else:
            vr = 1.0

        signal = None

        if position == 0:
            # 日线趋势向上 + 中枢突破 → 三买
            if trend and trend.type == TrendType.UP and state.centers:
                last_c = state.centers[-1]
