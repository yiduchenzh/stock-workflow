### 模块B — 涨停"数够5天再决定"

| 文章宣称 | 实测(5539只/18个月) | 结论 |
|---|---|---|
| 涨停后次日追, 平均亏3.2%、胜率38% | 次日开买当日收:**-0.18%**, 胜率44.0%(n=15,482) | 方向对、数字夸大 |
| 涨停后次日开买持5日 | **-0.37%**, 胜率41.6%, 超额**-0.64%** | 追涨停是负alpha |

### 3.1 涨停隔夜溢价(买=涨停价, 卖=次日开盘)

| 分层 | 样本 | 次日跳空均值% | 跳空中位% | 跳空>0概率% | 次日收盘均值% |
|---|---|---|---|---|---|

| 首板 | 15,399 | **+1.38** | +0.77 | 58.8 | +1.20 |
| 2连板 | 2,232 | +2.37 | | 62.0 | +1.94 |
| ≥4连板 | 468 | +3.44 | | 71.2 | +2.56 |

| **非一字板(有成交机会)** | 22,034 | +1.44 | +0.77 | 59.0 | +1.28 |
| 首板+早盘即封(振幅<3%) | 718 | **+4.38** | | 74.4 | +3.78 |
| 首板+**巨量(>3x5日均量)** | 445 | **-0.31** | | **37.8** | -0.49 |
| 首板+温和量(1~2x) | 8,878 | +1.21 | | 58.7 | +1.04 |
| 首板+低位(分位<0.35) | 1,838 | +0.87 | | 55.8 | +1.01 |
| 非涨停涨7~9.5%(未封板) | 13,897 | **-0.52** | | 33.2 | -0.26 |

**分年度稳健**: 2025跳空+1.90% / 2026跳空+1.48% → 两年一致为正 ✅

**现实约束(必须打折)**:
1. 一字板占 4.5%~6.7%, 这部分 +7.4% 的溢价**拿不到**
2. 数据只能看到"收盘封在涨停价"的板; **当天冲上涨停又炸板的样本不在这批里**, 而打板者恰恰会被套在这些板上
3. 参照口径: 收盘涨7~9.5%但未封板的个股, 次日跳空 **-0.52%**。若按 30% 概率炸板测算, 单笔期望 ≈ **+0.65%**
4. 日线回测**无法建模排队成交率** → 该 +1.44% 属于"理论溢价", 不是可直接交易的alpha

## 四、结论

1. **方法论层面**(主线思维/位置优先/不追高/五步闭环/心理纪律): 有价值, 属认知与纪律, 不产生alpha但能减少亏损交易。
2. **技术规则层面**(梯队/持续放量/三招合一/尾盘八条件/五层优先级/等5天): 在 5539只×18个月 真实数据上, **没有一条提供统计显著的正alpha**; 部分显著为负(三招合一 t=-4.5); 组合收益全部来自beta, 且分年度在2026年集体转负。
3. **唯一统计显著的正向规律**是涨停隔夜溢价, 但其可交易性受**成交率**约束, 需逐笔/委托队列数据建模后才能落地。
4. **唯一稳健可用的组合级改进**是大盘环境门控(等权指数MA20), 价值在降回撤而非增收益。
