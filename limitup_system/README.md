## 一、体系来源与蒸馏映射

| 来源 | 蒸馏到 | 核心规则 |
|:---|:---|:---|
| 文字①《涨停打板选股》 | `screener.py` | 涨停前一日量能只归三类：**缩量地量**(高连板) / **温和放量**(稳健) / **翻倍爆量**(博弈)；位置决定信号性质（高位一律排除）；次日开盘分时强弱是最终确认 |

| 多周期战法 | `multi_timeframe.py` | 日线定方向 → 60分定强弱 → 15分找买点 → 5分/分时执行（四级金字塔） |

## 三、打板选股核心逻辑（screener.py）

```
对每只股票最后一根K线（今日）：
  量比 = 今日成交量 / 前5日均量（不含当日）
  位置 = 高位(距60日高点<5% 或 20日涨幅>30%) / 低位 / 上涨中途

  缩量地量: 量比≤0.6 + 振幅≤3% + 小实体(≤2%) + 站稳5/10日线 + 非高位
  温和放量: 量比1.3~1.8 + 收阳 + 涨幅1~4% + 无长上影 + 均线多头 + 非高位
  翻倍爆量: 量比≥2 + 振幅≥6% + 冲高回落(上影) + 站稳5日线 + 逼近60日高点 + 非高位

  评分 = 形态基础分(45/40/35) + 位置分(低位25/中途15/高位-100) + 量价配合加分
  A≥80 首选 / B≥65 备选 / C≥50 观察 / D 放弃
```

**关键避坑（文字①原文量化）**：
- 高位缩量地量 = 无人接盘（下跌前兆），**排除**；高位爆量长上影 = 出货，**排除**
- 温和放量带长上影 = 借涨出货，**排除**
- 形态只是概率提升，次日开盘分时（高开/均价支撑/放量拉升）才是最终确认

## 四、昨收价战法核心逻辑（strategy.py）

```
9:25  锁定昨收基准
9:30-9:33  开盘3分钟定强弱：3根5分钟K全站上=强势/全压制=弱势/穿越=震荡
盘中 四态判定（分钟K）：
  强势: 所有分钟K最低≥昨收 → 回踩低吸/坚定持有，仓位5-6成
  弱势: 所有分钟K最高≤昨收 → 不抄底/反弹减仓/尾盘清仓，0仓
  震荡: 围绕昨收穿越 → 空仓/小仓1-2成
  骗线: 曾穿越但近5根K(25分钟)稳定一侧 → 假突破/假跌破，0操作

进场1 弱转强: 跌破昨收 → 2根K(10分钟)内放量收回站稳 → 低吸，止损=挖坑最低点-0.01
进场2 强延续: 开盘站稳昨收 + 回踩不破(容差0.2%) → 加仓，止损=昨收-0.01
离场1 破位:   曾站上昨收 → 最近3根K(15分钟)有效跌破 → 无条件清仓
离场2 弱势:   全天压制昨收 → 尾盘统一清仓
```

## 五、回测口径（诚实声明）

- **打板隔日**：T-1 收盘评分 → T 开盘买 → T+1 开盘卖。T+1 合规。一字板跳过（买不进）。
  含双边佣金万2.5 + 印花税万5。**开盘价成交模型无法模拟盘中封板买不进/卖不出，
  实际胜率通常比回测低 5-10%**。
- **昨收战法**：A股 T+1 下"开盘买收盘卖"实际不可行（除非有底仓做T），提供两个口径——
  a) 纯日内统计参考（有底仓做T的场景） b) 隔夜 T+1 合规（真实可执行）。
- 回测是概率估计不是承诺。形态出现 ≠ 次日必涨停，**仓位风控是长期盈利的核心**。

## 速度优化（三级缓存，2026-08-07）

| 层 | 机制 | 效果 |
|:---|:---|:---|
| 内存 | `_kline_cache` TTL 300s / `_market_cache` 60s | 进程内秒回 |
| SQLite | `cache/kline.db` 日K持久缓存（盘后48h/盘中10min，每线程读连接无锁） | **二次运行 K 线全命中** |
| 文件 | `cache/market_full.json` 全量列表（盘后全天/盘中5min） | 二次运行 0.05s 命中 5538 只 |

实测（2026-08-07，1999只候选，16并发）：
- **冷启动（每天第一次）：167s**（全量拉K线网络硬成本）
- **二次运行（缓存命中）：~7s**
- 失败票快速失败（退避上限1.5s + 腾讯重试1次），不烧时间
- 数据源限流防护：新浪456 → 自动切东财/腾讯；通达信主源不封IP
